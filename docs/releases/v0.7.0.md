# 拾用 · Useleaf 0.7.0

把遇见的英文，变成用得上的表达。

首个公开版本。原「拾词 / WordShelf」现更名为「拾用 / Useleaf」，配套全新叶片对话图标，源码与原创图标按 MIT 许可开源。

## 下载与安装

- **M 系列 Mac / Apple Silicon**：下载 `Useleaf-0.7.0-macos-arm64.dmg`，将 Useleaf 拖入「应用程序」。ZIP 提供同一应用；`SHA256SUMS` 可校验下载完整性。
- **macOS 14+**；Apple 本机句子翻译需要 **macOS 15+** 和中英语言包。
- 当前为 **arm64** 构建，未提供经过验证的 Intel / universal 包。
- **ad hoc 签名、未经过 Apple 公证**。首次打开可能被系统拦截，请确认来源后按照 [Apple 官方说明](https://support.apple.com/102445)操作。不要关闭系统安全保护。
- 在 Apps / Spotlight 搜索 **Useleaf**。全局划词需要你在系统设置中授予辅助功能权限；手动查询无需该权限。

## 已包含

- 选中单词、短语或句子后按 **⌃⌥D**，查看中文释义或本机翻译，**⌘S** 收藏原文。
- 770,611 条 ECDICT 离线词条，英式 / 美式系统发音，生词本直接听音。
- 选项式工作与生活场景设置，自动推荐「希望会用 / 看懂即可 / 暂存参考」。专业词先以理解为目标，有具体说写需求才升级。
- 主动回忆、自评和间隔复习，搜索、删除撤销、TXT / CSV 导出。
- 本机存储，无账户、遥测、API Key 或云端大模型。Apple 语言包首次准备需要系统下载。

## 旧版升级

先退出 WordShelf，再打开 Useleaf。保留原应用标识和 `com.yuki.wordshelf` 数据目录，已有收藏、场景设置与复习进度可继续使用。系统可能需要刷新更新后应用的辅助功能授权；具体步骤见 README。

## 已知范围

界面主要为简体中文，学习方向为英译中。扫描 PDF / 图片没有 OCR；自由说写目前通过对照参考自评，不自动批改。推荐与复习间隔采用可解释的启发式估计，不保证精准推断个人需求。

**English:** Useleaf is a native, local-first macOS English lookup and practice app. Select English and press **Control–Option–D** to look it up, listen, and save the original. Practice useful expressions through personal scenarios, active recall, self-assessment and spaced review. This first public release provides an **Apple Silicon / arm64** DMG and ZIP for **macOS 14+**; local sentence translation needs **macOS 15+** and Apple language packs. Downloads are **ad-hoc signed and not Apple notarized**; see [Apple's security guide](https://support.apple.com/102445). Existing WordShelf data is retained.
