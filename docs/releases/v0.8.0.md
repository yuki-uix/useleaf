# 拾用 · Useleaf 0.8.0

随手查，轻轻收，需要表达时再找回来。

## 更新

- 启动后安静驻留菜单栏，不自动打开管理窗口。
- 划词按 **⌃⌥D** 打开约 360pt 宽的原位浮窗，高度随内容调整。默认保留原文、简明释义、发音与收藏；编辑原文和更多释义按需展开。
- **收藏原文 / ⌘S** 后在原位确认，不跳转到学习或管理。按 **Esc** 或点击外部，继续原来的阅读。
- **左点菜单栏小啄** 打开紧凑的收藏检索面板。按英文原文片段搜索，不区分大小写；单个匹配自动展开，其余可手动展开。
- 收藏面板内直接查看临时释义、切换英美发音或 **复制原文**。成功复制后关闭面板并回到之前的写作应用，由用户自行 **⌘V** 粘贴。
- **右键菜单栏小啄** 可手动查词、管理收藏与选项、导出原文或退出。场景选项与自愿回忆保留在次级管理窗口中，不成为收藏后的任务。
- 不加入每日任务、强制分类或中文意图搜索。检索仍匹配已收藏的英文原文。
- 紧凑浮窗与收藏面板跟随系统浅色 / 深色外观。小啄的收藏反馈保持安静，并遵循“减少动态效果”。

## 数据与兼容性

- 沿用 `com.yuki.wordshelf` 应用标识与数据目录，`words.json` 仍为原文字符串数组；已有收藏、场景设置与复习记录可继续使用，无需迁移。
- 收藏面板中的搜索词、释义和翻译只留在当前面板内存中，不写入收藏字段，也不新增遇见日期或复习记录。
- 只有查译浮窗或收藏面板可见时，才监听外部鼠标按下事件以关闭浮窗；不读取按键或页面内容，也不保留事件历史。
- 主动点击 **复制原文** 会将完整原文放入系统剪贴板；划词读取的临时 `⌘C` 回退仍遵循原有快照恢复规则。详情见 [隐私说明](../PRIVACY.md)。
