# 拾用 · Useleaf 0.7.1

清瓷白的新图标，以及安静陪你回想表达的小啄。

## 更新

- 新的啄木鸟图标：冷白底、墨蓝鸟身、薄荷叶翼与珊瑚红鸟冠，保留引号元素。
- 界面使用更清透的冷白、墨蓝和浅薄荷配色。
- 收藏真正写入成功后，小啄轻点一次并提示“已收好，继续阅读。”；重复收藏或保存失败不会触发成功反馈。
- 回忆提示准备就绪且未揭示参考时，小啄安静等待；本轮结束时收翅休息，显示现有真实完成数与下次复习日期。
- 收藏动画静音、不循环，尊重 macOS 的“减少动态效果”设置。
- 角色状态仅保留在当前界面和内存中。收藏格式、学习推荐和复习规则保持兼容。

## 下载与升级

下载 `Useleaf-0.7.1-macos-arm64.dmg` 并拖入「应用程序」，或使用 ZIP；`SHA256SUMS` 提供完整性校验。支持 Apple Silicon / M 系列 Mac、macOS 14+；Apple 本机句子翻译需要 macOS 15+ 和中英语言包。

先退出旧版本，再打开新版本。沿用 `com.yuki.wordshelf` 数据目录，已有收藏、场景设置和复习记录可继续使用。更新后的辅助功能授权可能需要在系统设置中刷新，步骤见 README。

下载使用 **ad hoc 签名，未经过 Apple 公证**。首次打开可能被系统拦截，请确认来源后按 [Apple 官方说明](https://support.apple.com/102445)操作，无需关闭系统安全保护。
