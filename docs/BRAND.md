# 拾用 · Useleaf

**把遇见的英文，变成用得上的表达。**

“拾”是阅读中随手收集，“用”是工作与生活中的说写需求。“拾用”与“实用”同音。
Useleaf 由 use 与 leaf 组成：一页小小的表达卡片，也是一片逐渐长出的新叶。

## 小啄与清瓷白

0.7.1 将原来的叶片对话轮廓发展为一只简洁的啄木鸟，角色名为“小啄”。
叶片成为翅膀，两枚引号保留“表达”的含义；直喙与珊瑚红鸟冠突出啄木鸟特征。

| 颜色 | 用途 |
| --- | --- |
| 清瓷白 `#F3F6FA` | 应用图标底色 |
| 墨蓝 `#193044` | 鸟身、引号和界面主色 |
| 薄荷 `#4ED7B5` | 叶片翅膀 |
| 珊瑚红 `#FF5D62` | 小面积鸟冠强调色 |
| 白色 `#FFFFFF` | 面部留白 |

使用平面色块和清晰轮廓，不依赖外部字体或图片。16 px 时简化翅膀上的引号，
保留辨识度；较大图标和应用内角色使用完整形状。

## 旅程中的三个触点

- 收藏真正写入成功后：小啄轻点一次，显示“已收好，继续阅读。”。已收藏、重复保存或失败不会触发成功反馈。
- 主动回忆：提示准备就绪且未揭示参考时，小啄安静等待。原文显隐仍按现有学习用途控制。
- 本轮结束：小啄闭眼休息，继续展示实际完成数和下次复习日期。

角色反馈不增加打卡、积分、养成或掌握度判断。收藏动画静音、不循环，遵循系统的
“减少动态效果”设置；角色状态仅在内存中，不增加收藏或学习文件字段。
