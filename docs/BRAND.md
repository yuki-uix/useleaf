# 拾用 · Useleaf

**把遇见的英文，变成用得上的表达。**

“拾”是阅读中随手收集，“用”是工作与生活中的说写需求。“拾用”与“实用”同音。
Useleaf 由 use 与 leaf 组成：一页小小的表达卡片，也是一片逐渐长出的新叶。

图标将叶片和对话气泡合为一个轮廓，以两枚引号点出表达。深青绿渐变
`#123F3B → #2F7D6D` 配象牙白 `#F7F4E8`，引号使用 `#1E5B4F`。
不依赖字母、字体或外部图库，小尺寸仍保留完整轮廓。

- 可编辑矢量：[Useleaf.svg](../Support/Brand/Useleaf.svg)
- 1024 px 预览：[Useleaf-1024.png](../Support/Brand/Useleaf-1024.png)
- 应用图标生成器：[make_icon.swift](../scripts/make_icon.swift)

应用内标记和图标生成器使用同一组轮廓坐标。菜单栏使用系统单色叶片符号。
原创图标与源码一同按 MIT 许可发布。

品牌从 0.7.0 起取代“拾词 / WordShelf”。应用文件名为 `Useleaf.app`，
Apps 中搜索 `Useleaf`。内部 Swift target、构建产物和
`com.yuki.wordshelf` 标识保留，确保已有收藏、学习资料和系统权限身份连续。
